### 🚀 Quick Start Template

**File: `main.py`**
```python
from fastapi import FastAPI

app = FastAPI(
    title="CAIO - JARVIS API",
    description="100 Days FastAPI Roadmap - Day 1 to 100",
    version="1.0.0"
)

@app.get("/")
def root():
    return {"message": "JARVIS ONLINE - FastAPI Day 1 Started"}

@app.get("/avengers/{name}")
def get_avenger(name: str):
    avengers = {"ironman": "Genius", "thor": "God", "hulk": "Smash"}
    return {"avenger": name, "power": avengers.get(name.lower(), "Unknown")}
